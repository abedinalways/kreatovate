# Kreatovate Project Suite

This repository contains three connected web projects developed for **Kreatovate**, an AI-powered marketing and business consulting company.  
Each project focuses on a unique part of Kreatovate’s digital ecosystem — from client onboarding experiences to workforce engagement and innovation showcases.

---

## 🚀 Overview

### 1️⃣ **Kreatovate – Main Site**

**Live:** [https://kreatovate.vercel.app/](https://kreatovate.vercel.app/)  
The official company website for Kreatovate — built to represent the brand, showcase its services, and communicate its vision.

**Features:**

- AI-driven business consulting showcase
- Service and team presentation pages
- Modern animations with **GSAP**
- Fully responsive design
- SEO optimized meta setup
- Contact and consultation form integration

**Stack:**  
`Next.js 15`, `TypeScript`, `Tailwind CSS`, `GSAP`, `Shadcn/UI`

---

### 2️⃣ **Workforce – Kreatovate**

**Live:** [https://workforce-kreatovate.vercel.app/](https://workforce-kreatovate.vercel.app/)  
A specialized internal platform designed to manage and highlight the **Workforce Experience** of Kreatovate.

**Features:**

- Clean and minimal landing page
- GSAP-based fade and motion effects
- Modular structure with easily scalable layout
- Consistent brand look matching Kreatovate main site
- Smart section flow optimized for readability

**Stack:**  
`Next.js`, `TypeScript`, `Tailwind CSS`, `Shadcn/UI`

---

### 3️⃣ **Bumps – Kreatovate**

**Live:** [https://bumps-kreatovate.vercel.app/](https://bumps-kreatovate.vercel.app/)  
A creative micro-project for visual storytelling and marketing experimentation — blending design, motion, and minimal content structure.

**Features:**

- Smooth animated transitions
- GSAP-powered sections
- Lightweight structure for fast load
- Built for brand presentation and testing new design ideas

**Stack:**  
`Next.js`, `GSAP`, `Tailwind CSS`, `TypeScript`

---

Each project is **independent** and deployable on **Vercel**, sharing a common design and technology foundation for consistent branding.

---

## 🧠 Developer Notes

- All projects are built with a modular, scalable architecture using reusable components.
- The design follows **Kreatovate’s brand identity**: dark elegant interface with gradient highlights.
- Uses GSAP for subtle animations and Shadcn/UI for consistent styling across projects.
